📋 每次启动的“标准流程”
第一步：启动后端（C++ 银行服务器）
打开第 1 个命令行窗口（Win + R → 输入 cmd → 回车）。

进入你的 C++ 项目文件夹（就是放着 bank_server.exe 和你那些 .cpp 文件的地方）。

cmd
cd C:\你的C++项目路径
（注意：把路径换成你电脑上实际的位置，比如 cd C:\Users\grayz\Desktop\bank）

运行后端程序：

cmd
./bank_server
或者（如果上面不行，试试这个）：

cmd
bank_server.exe
看到提示 Bank API Server 启动成功! 监听地址: http://localhost:8080，说明后端好了。这个窗口不要关，保持运行。

第二步：启动前端（React 界面）
打开第 2 个全新的命令行窗口（同样 Win + R → cmd → 回车）。

进入前端项目文件夹：

cmd
cd C:\Users\grayz\Desktop\react\bank-frontend
启动前端开发服务器：

cmd
npm run dev
看到提示 Local: http://localhost:5173/，说明前端也好了。

按住 Ctrl 键点击那个 http://localhost:5173/ 链接，或者在浏览器地址栏手动输入它，就能打开银行系统了。

💡 小技巧：用 VS Code 一键开两个终端
如果你用 VS Code 打开项目，可以省去每次手动开两个 CMD 窗口的麻烦：

打开 VS Code。

菜单栏 → Terminal（终端） → New Terminal（新建终端），或者按快捷键 Ctrl + ``（注意是数字1左边的那个反引号键）。

它会打开一个终端面板。

点击终端面板右上角的 “+”号（Split Terminal，拆分终端），这样就出现两个独立的终端并排。

左边终端 输入 cd C:\你的C++项目路径 然后 ./bank_server。

右边终端 输入 cd C:\Users\grayz\Desktop\react\bank-frontend 然后 npm run dev。

这样以后每次打开 VS Code，直接在这两个终端里输入对应的启动命令就行了。

⚠️ 如果提示“端口被占用”（Address already in use）
如果之前没有正常关闭，导致端口还占着，会启动失败。

前端（5173端口）被占：在运行 npm run dev 的窗口按 Ctrl + C，输入 Y 确认，然后重新运行。

后端（8080端口）被占：在运行 ./bank_server 的窗口按 Ctrl + C 强制关闭，然后重新运行。

📌 总结（记住这两条命令就够了）
服务	要输入的目录	要输入的命令
后端	cd C:\你的C++项目目录	./bank_server
前端	cd C:\Users\grayz\Desktop\react\bank-frontend	npm run dev
两个都启动后，浏览器打开 localhost:5173 就行。

现在你可以先试着关掉所有窗口，按这个步骤重新启动一次，看看能不能顺利回到银行系统的界面。如果哪里卡住了，告诉我你卡在哪一步。












你现在必须做的“合体”动作（非常关键）
要想让整个项目（C++ + React）跑起来，你需要在两个不同的窗口同时运行这两个东西：

第一步：启动你的 C++ 后端（大脑）
在终端（命令行）里，编译并运行我给你的 server.cpp（它已经包含了你的全部代码）：

bash
g++ -std=c++17 -pthread server.cpp Bank.cpp Account.cpp Transaction.cpp mydbms.cpp -o bank_server -lsqlite3
./bank_server
看到这行字就成功了：

text
🏦 Bank API Server is running!
📍 Listening on http://localhost:8080
此时，你的 C++ 银行系统已经“开门营业”了，正在等待前端来办理业务。

第二步：启动 React 前端（遥控器）
另开一个终端，进入前端项目目录，启动界面：

bash
cd bank-frontend
npm run dev
看到 Local: http://localhost:5173 后，打开浏览器访问这个地址。

终极验证：两个东西是不是真的连上了？
你打开浏览器里的 React 界面（localhost:5173），然后把刚才运行 C++ 的那个终端窗口盯着看。

当你点击前端界面上的“刷新”或“创建账户”时，你会发现 C++ 终端里会立刻打印出下面这些话：

text
[API] GET /api/accounts called
[API] POST /api/accounts called
Table created successfully
insert successful
这铁证如山！ 它证明前端的每一次点击，都实实在在地在跑你那几千行的 Bank.cpp、Account.cpp 和 mydbms.cpp 代码。

json.hpp 下载地址：

保存路径：请务必将这两个文件直接保存在你的 C++ 项目根目录下（和 server.cpp 同级），这样 #include "httplib.h" 才能被找到。
